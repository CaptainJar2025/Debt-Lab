# Built from an engineer’s afternoon of questions

Debt Lab was built with AI tools from the musings of a chemical engineer working in capital projects. It began as an afternoon project to understand debt, cash flow and the choices that open up after payoff.

The aim is to get the math right. It has survived the creator’s testing and has automated tests, but neither is an independent audit or proof that every result is correct. Lender rules, assumptions and software bugs can all change the answer.

If an afternoon project is the entire basis of your financial modeling, you might be cooked. Use this to ask better questions, check the workings, and compare the answers with statements and independent calculations before committing money.
